# ✅ To-Do List Manager – Python Mini Project  

This mini project is a **To-Do List Manager** built using **Object-Oriented Programming (OOP)** concepts in Python.  
It allows users to **add, edit, mark, and view tasks** with different priorities, helping improve task organization and productivity.  

---

## 🚀 Project Overview  
The program provides an interactive **menu-driven interface** that helps users manage their daily tasks efficiently.  
Each task includes a **description, priority level (High, Medium, Low), and completion status**.  

### 🧩 Features  
- ➕ **Add Tasks:** Create new tasks with a description and priority.  
- ✏️ **Edit Tasks:** Modify task details or priority anytime.  
- ✅ **Mark as Completed:** Easily mark tasks as done.  
- 📋 **View All Tasks:** Display the complete list with status and priority.  
- ❌ **Exit Option:** Gracefully closes the program.  

---

## 🧠 Concepts Practiced  
- Classes and Objects in Python  
- Constructor (`__init__`) usage  
- Functions and loops  
- Conditional statements (`if`, `elif`, `else`)  
- Input handling and menu navigation
